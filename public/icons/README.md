# Icon sources

These SVG files are downloaded originals, served locally without a runtime third-party request.

- `shield`, `notices`, `bug`, `alert`, `arrow`, `external`: [Tabler Icons](https://github.com/tabler/tabler-icons), MIT, via [Iconify](https://iconify.design/).
- `supabase`, `github`, `cloudflare`, `vercel`, `google-cloud`, `netlify`, `railway`: [Simple Icons](https://github.com/simple-icons/simple-icons), CC0-1.0, via Iconify.
- `aws`, `azure`: [SVG Logos](https://github.com/gilbarbara/logos), CC0-1.0, via Iconify.
- `sakura.ico`: favicon supplied by [さくらインターネット](https://www.sakura.ad.jp/favicon.ico).

Brand marks remain the property of their respective owners. SVG title elements are added for accessibility. No icon paths are modified.
